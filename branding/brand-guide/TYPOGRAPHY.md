# Typography

Primária: Montserrat SemiBold/Bold para títulos, campanhas, navegação e destaques.
Secundária: Inter Regular/Medium para textos, informações, e-commerce e interface.
O logotipo é desenho proprietário e não deve ser recomposto com fonte.
