# Color & Type

## Core colors
- Charcoal #1F1F1F
- Off White #FAF8F3
- Sand #E8DFD1
- Cobalt #0057FF
- Orange #FF6A00

## Semântica
Cobalt = visão, futuro, CTA, plano principal.
Orange = ação, ruptura, detalhe.
Charcoal = estrutura e atitude.
Off White = clareza e editorial.
Sand = calor e materialidade.

## Type
Headlines: Montserrat SemiBold/Bold.
Body/UI: Inter Regular/Medium.

Orange nunca deve ser a única cor de texto pequeno em fundo claro.
