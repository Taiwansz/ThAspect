# Logo Rules

Use os masters em branding/logos/svg/.

Prioridade:
1. primary
2. compact
3. monogram
4. badge

Área de proteção mínima = 25% da altura do monograma.

Nunca:
- esticar
- trocar as cores-base
- aplicar efeito 3D
- adicionar sombra/glow
- rotacionar a assinatura
- reconstruir com fonte
- colocar em fundo sem contraste
