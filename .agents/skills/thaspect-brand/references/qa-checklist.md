# QA Checklist

Antes de aprovar qualquer peça:
- [ ] usa assets oficiais
- [ ] mantém proporções do logo
- [ ] respeita a paleta
- [ ] Orange não domina
- [ ] Cobalt tem papel claro
- [ ] tipografia está correta
- [ ] existe gesto de perspectiva intencional
- [ ] não há efeitos genéricos de IA/SaaS
- [ ] streetwear não virou grunge aleatório
- [ ] copy é curta e direta
- [ ] contraste é suficiente
- [ ] mobile/responsivo foi considerado
- [ ] a peça ainda é reconhecível sem o logo
