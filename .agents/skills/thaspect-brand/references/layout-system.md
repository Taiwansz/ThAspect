# Layout System

## Grid
Base editorial limpa, módulos rígidos e uma ruptura controlada.

## Perspectiva
Aplicar um ou dois recursos por composição:
- diagonal de 24°
- recorte angular
- frame trapezoidal
- grid de perspectiva
- plano sobreposto
- tipografia cortando limites
- fotografia parcialmente fora do frame

## Densidade
Não lotar a tela. O contraste entre grandes áreas calmas e um gesto angular forte é parte da marca.

## Cantos
Interface: 8–14 px.
Editorial/print: preferir cantos retos.
