# ThAspect Brand Skill

Esta skill é a fonte operacional da identidade do ThAspect.

## Regra principal
Toda decisão visual deve reforçar perspectiva, ângulo, movimento e expressão individual.

## Quick rules
- Base: Off White + Charcoal.
- Cobalt = visão/ação principal.
- Orange = ruptura/microacento.
- Sand = materialidade.
- Diagonais controladas em 12°, 24°, 30° ou 45°.
- Montserrat para headlines; Inter para interface e corpo.
- Fotografia urbana, arquitetônica e direcional.
- Evitar roxo tech, neon verde, gradientes genéricos e estética SaaS.
- Evitar streetwear clichê com grunge/spray sem função.
- Todo layout precisa ter ao menos um gesto de perspectiva: corte, enquadramento, plano, recorte, diagonal, grid ou mudança de escala.
