# ThAspect — Primeira Versao (V1)

Este diretorio preserva os artefatos historicos da primeira versao do sistema e-commerce da marca **ThAspect**, desenvolvidos originalmente no contexto academico de Banco de Dados e Aplicacoes (registrados no CS-Vault-2026).

## Conteudo da V1

- `ThAspectbd.sql`: Script DDL do banco de dados relacional (`ThAspectDB`), definindo as tabelas essenciais: `Clientes`, `Produtos`, `Carrinho`, `Carrinho_Itens`, `Pedidos`, `Pedidos_Produtos`, `Cupons` e `Recomendacoes`.
- `ThAspect - DER.pdf`: Diagrama Entidade-Relacionamento (DER) oficial das entidades e chaves relacionais da V1.
- `DOCUMENTACAO THASPECT.pdf`: Documentacao tecnica completa do sistema e-commerce ThAspect (requisitos funcionais, regras de negocio, especificacao de arquitetura em Flask/Bootstrap e telas do MVP original).
- `ThAspect.pdf`: Documento formal de analise de requisitos para a base de dados relacional.
